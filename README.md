### 1° Laboratório para disciplina Organização e Arquitetura de Computadores - Departamento de Ciência da Computação(CIC) - UnB

O projeto consiste na elaboração de um montador(Assembler) com o programa RARS, em que recebe um arquivo assembly(.asm) e retorna 2 saidas: um arquivo de dados: .data (.mif) e um arquivo de texto: .text(.mif)
